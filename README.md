# Quiz Application

A simple Java-based Quiz Application that allows users to answer a series of multiple-choice questions and receive a score at the end. This project is designed to demonstrate basic Java concepts such as object-oriented programming, control flow, and user input handling.

## Features

- Console-based interactive quiz
- Multiple-choice questions
- Score calculation at the end of the quiz
- Easy to customize with your own set of questions

## Technologies Used

- Java (Core Java)
- OOP Concepts (Classes, Objects, Encapsulation)
- Scanner for user input
